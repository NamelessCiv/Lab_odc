# CTF

Un dossier par challenge, dans la bonne catégorie :

```
ctf/<categorie>/<nom-du-challenge>/
├── README.txt   # énoncé, format du flag, ce qui a déjà été tenté
├── <fichiers fournis>
└── solve/       # scripts de résolution et notes
```

Catégories : crypto, web, malware, stegano, forensics, reverse, misc.

Malware : toujours en zip chiffré, mot de passe `infected`. Ne jamais exécuter.

⚠️ Ce dépôt est public : tout ce qui est poussé ici est visible.
